# PR 본문 템플릿

서브 에이전트가 제목과 본문을 작성한다. `SKILL.md`의 언어 선택 규칙에 따라 한국어 PR에 이 템플릿만 사용한다. `ZOOSIXPARK/react-component-generator`는 한국어가 기본이며, 사용자가 해당 PR의 언어를 지정하면 우선한다.

## 작성 기준

- 실제 diff와 커밋을 근거로 문제와 변경 후 동작을 먼저 설명한다. 작업 과정이나 파일 목록만 나열하지 않는다.
- 검증에는 실제 실행한 명령과 결과를 쓴다. 미실행 검증은 그 사실과 이유를 적고, 로컬 결과를 CI 결과로 표현하지 않는다.
- 위험·배포·관련 이슈는 해당할 때만 남긴다. 이슈 번호, 검증 결과, 위험을 추측해서 채우지 않는다.
- 작은 PR은 요약과 검증만으로 줄일 수 있다. 저장소의 필수 PR 항목은 유지하고 아래 내용을 그 형식에 맞춘다.
- 중괄호 자리표시자와 안내문은 실제 내용으로 교체하거나 삭제한다.

## 본문 템플릿

```markdown
### 요약

{어떤 문제 또는 요구가 있었으며, 이 변경으로 사용자나 시스템의 동작이 어떻게 달라지는지 설명}

### 주요 변경

- {리뷰어가 알아야 할 변경과 그 이유}

### 검증

- `{실행한 명령}` — {실제 결과}
- 미실행: {검사와 실행하지 않은 이유; 해당 없으면 삭제}

### 위험 및 배포

{호환성, 마이그레이션, 배포 시 고려사항 등 확인된 사항; 해당 없으면 제목과 함께 삭제}

### 관련 이슈

{확인된 관련 이슈 링크; 해당 없으면 제목과 함께 삭제}
```
